### Глоссарий

| Термин | Описание |
|--------|----------|
| **SDK** | Software Development Kit |
| **On-Demand** | Режим запроса данных по необходимости |
| **Polling** | Режим периодического опроса |
| **LRU** | Least Recently Used (алгоритм вытеснения кэша) |
| **TTL** | Time To Live (время жизни данных в кэше) |
| **Multiton** | Паттерн управления несколькими именованными экземплярами |
| **Facade** | Паттерн упрощающий сложный интерфейс |
